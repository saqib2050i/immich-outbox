Download the app

No app is bundled with this server build. See companion/README.md for how to build one.

This build is debug-signed. Android will refuse to install it over a copy signed with a different key, so an update may need the old one uninstalled first. Setting a signing key in CI removes that step for good.

Installing it

  1. Tap Download the app. Android will warn about installing from this browser — allow it for the browser when asked.
  2. Open the downloaded file and install.
  3. Open Photo relay companion, enter this server's address and the pairing code from Settings → Phone companion on the dashboard, then tap Save and check in.
  4. Tap Open accessibility settings and switch the app on. It can only see Google Photos.

Updating later is the same thing again — the pairing code and settings survive. Only the accessibility switch may need turning back on.

What it can do

The app declares two permissions, internet and network state, and nothing else. It holds no storage permission, so it cannot read, move or delete a photo — it presses the button, and Google Photos removes only what it has already backed up. Its accessibility service is restricted to Google Photos and can see no other app.
